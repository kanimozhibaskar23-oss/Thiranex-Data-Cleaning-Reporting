\# Data Cleaning \& Reporting Automation



\## Project Overview



This project automates data cleaning and reporting using Python.



\## Technologies Used



\- Python

\- Pandas

\- Matplotlib

\- OpenPyXL

\- Excel



\## Key Features



\- Handles missing values

\- Removes duplicate records

\- Standardizes inconsistent city names

\- Converts data into appropriate data types

\- Generates cleaned CSV data

\- Generates an automated Excel report

\- Creates a visual summary of purchase data



\## Output Files



\- raw\_customer\_data.csv

\- cleaned\_customer\_data.csv

\- automated\_data\_cleaning\_report.xlsx

\- purchase\_summary.png



\## Conclusion



The project demonstrates how Python can automate data preprocessing, cleaning, reporting, and visualization workflows efficiently.
